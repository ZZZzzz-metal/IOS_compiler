# 给1/2/5号的运行调试接入

## 合入与接口

只合入 debugger/ 与 docs/handoffs/03.md，起点 baseline-v0.1.0。根入口、能力表与共享兼容注册仍由1号修改，不直接把本模块candidate写成verified-ipad。

1. 先合入2号compiler，再合入本模块，重跑两者真实检查。生产资源基址由1号配置，不保留开发时的sibling路径。
2. 将runtime/debugger源代码、compiler/linker/sysroot/stdlib、UI及许可的精确字节放入统一资源表。本模块candidate只验证运行/调试资源字节并关联真实编译证据，**未校验完整产品资源包**。
3. 共同审定CompatibilityProfile。实测旧WASI+DWARF4；冻结后改变组件资源需新组合。源码snapshot/build/profile必须原样传入调试器。
4. CompilerAdapter的writeResource与调试Worker读取共用虚拟路径；或先registerResource交入本次内存会话。不得接受编译失败、过期requestId或旧编辑快照。实验页桥接CompilerProbe的真实compiled产物不等于产品编译注册已完成。
5. 4号消费协议，继续前同步失效pause/frame，分页变量，检测eventSeq缺口后resync；ACK不得覆盖权威状态。frameId不能用数组下标替代。
6. 生产使用Worker包装层，后台调用background、卸载调用dispose，隔离解析/执行与页面主线程。

## 5号独立复测

运行 node --test debugger/checks/*.test.mjs，再以独立源码检查同一行多调用、递归作用域、改代码再编译、vector扩容、空/长字符串、无效指针、输出限额、停止后再编译。检查真实机器状态，不只核对页面日志。

## iPad联合关卡（未执行）

1. 1号提供真实设备可用的安装或HTTPS入口，包含全角色资源。记录型号、iPadOS、宿主/安装形态及组件版本。
2. 首次准备后完全退出、断Wi-Fi/蜂窝、关闭辅助电脑。重开并校验完整资源，不用缓存按钮代替冷启动。
3. 粘贴此前未编译的C++程序，含循环、递归、数组、指针、空与非空vector、短长string。绑定源码断点，核对实际绑定位置与暂停值。
4. 进入/跳过/跳出，切换递归调用者帧，再继续。修改源码重编译，旧会话/帧不得覆盖新状态。
5. 普通C11重复编译、stdin、断点、数组/指针和输出；运行死循环，验证页面响应、实际停止及新会话正常调试。
6. 暂停超过运行预算再继续、后台切换、内存压力、缓存清理、草稿恢复与复制导出逐项记录。性能与可观测内存实测，未知保持未测。
7. 5号独立验收G2，1号审核证据后冻结路线。当前没有真实设备和安装产物，桌面证据不能改写成iPad通过。

## 共享修订建议

- 根入口可标注运行调试原型已实现、真机待验证，并链接独立命令；不能因import成功即报告产品就绪。
- 能力表按环境与具体证据更新；现有协议够用，无需建立第二套版本。异步Pause仍不开放，断点/三种单步/变量/栈需求保留。
- 完整离线清单、安装、许可、稳定保存与导出仍由集成层完成。实验Service Worker只管/debugger/，不接管根应用，不代表发行级缓存修复/升级策略。
