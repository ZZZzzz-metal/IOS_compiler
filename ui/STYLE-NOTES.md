# 界面样式维护说明

用户已选择**浅色纸面工作台**：源码为主体，绿色用于主要操作，琥珀色用于暂停/保存异常，红色用于停止/错误。保持轻量分隔与清晰层级，不继续增加装饰性卡片。样式入口为 `style.css`，页面结构与内联图标在 `probe.html`。

## 色彩变量

| 用途 | 当前变量与色值 |
|---|---|
| 纸面 | `--page: #f3f5f1`、`--paper: #ffffff`、`--paper-soft: #f8faf6`、`--code-paper: #fffefa` |
| 文字 | `--ink: #28352e`、`--muted: #647168`、`--faint: #7e8982` |
| 分隔 | `--line: #dfe5dd`、`--line-strong: #bac8bd` |
| 主要操作 | `--green: #28644c`、`--green-dark: #1f503c`、`--green-soft: #edf5ed`、`--green-line: #b8cfbc` |
| 暂停/提示 | `--amber: #8a611b`、`--amber-soft: #fff7e3` |
| 错误/停止 | `--red: #a53d35`、`--red-soft: #fff1ec` |
| 文字选择 | `--selection: #cbe4d5` |

当前固定 `color-scheme: light`，没有跟随系统切换主题。部分语法高亮、边框和交互细节仍使用局部色值；改主题时必须一并核对，不能只替换根变量。

## 布局与输入尺寸

- 默认源码与 340px 侧栏并排；`1190px` 以下侧栏缩至 300px，压缩工具栏与左右留白。
- `980px` 以下改为单栏，用“代码 / 调试与输入输出”切换；`640px` 以下重新排列页头、文档操作与调试按钮，保留安全区域间距。
- 粗指针规则以主要控件最小高度 **44px** 为目标；桌面部分次要控件为 32–40px。现有 `#find` 明确保留 40px，`.resource-button` 的 34px 规则也未被通用触控选择器覆盖，不能宣称所有控件均达到 44px。
- 代码与行号必须保持 **24px 行高**；行号按钮是为源码对齐保留的 24px 例外，触控可使用“切换断点”按钮。定位与查找滚动在 `main.mjs` 中也按 24px 计算。
- `#source` 与 `#highlight` 的字体、字号、字重、行高、字距、内边距、tab-size 和连字设置必须一致；窄窗与粗指针覆盖规则也须同时修改两层，不能单独调整 textarea。行号的顶部内边距同步对齐文本层。

## 资源与真实状态

图标全部由页面内联 SVG symbol/use 提供；中文界面使用系统字体栈，源码使用本机等宽字体栈，无外部字体或图标网络依赖。

`main.mjs` 的 `data-execution-state`、`data-resource-ready`、`data-source-view`、`data-save-state` 仅映射实际编译/会话、资源校验、编辑视图与保存回调；`data-panel` 只控制用户选择的窄窗面板。CSS 只负责表现，不生成暂停、保存成功或离线就绪状态，也不改变按钮的真实可用条件。本机资源校验成功不等于完整产品离线验收通过。

后续由 **1号重新打包**：将本轮 HTML/CSS/脚本纳入离线资源清单，重新生成校验和及交付包；已有生成包不会自动包含工作区中的样式修改。真机验收状态继续以集成记录为准。
