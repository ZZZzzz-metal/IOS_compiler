# 平板更新到v0.4.3

日期：2026-10-27。本版合入4号准备/导入竞态修复与浅色工作台，REV-004/005待5号独立复验；3号两个监视求值问题尚未修复。完整验证范围见 [集成报告](UI-RACE-INTEGRATION-2026-10-27.md)。

1. 在旧工作台先导出“完整草稿”到“我的iPad”，停止旧调试并关闭旧工作台，保留旧图标和网站数据。
2. 首次更新时电脑保持开机，两台设备接同一可互访Wi-Fi。Safari打开 [新版固定入口](https://100.65.235.35:4187/releases/ipad-web-probe-1934f34d48ba1a8c94eadd93/index.html)，核对 `ipad-web-probe-1934f34d48ba1a8c94eadd93`、50项、60,847,962字节。电脑严格TLS检查已通过，平板互通仍需实际确认。
3. 已安装并信任同指纹测试证书者无需重复安装。首次准备请按 [完整平板手册](IPAD-USER-MANUAL.md) 手动核对公开证书：名称 `iPad Debugger Local Test Root a065aa18`，DER SHA-256 `87991d2b7d332034beddb95ed35ddabc906c0e0b2bd1dd174ec4a25b826e349f`，到期时间2026-11-02北京时间09:29:59。启用根证书信任会改变设备TLS信任范围，不绕过浏览器警告。
4. 点“准备离线资源”，保持前台至50项全部通过；为**新版固定准备页**添加主屏图标，例如“算法工作台0.4.3”。从新图标联网重开、检查资源、打开工作台，再点“校验本地资源”。校验期间运行、调试及再次校验应禁用，失败后可重试校验。
5. 浅色工作台窄窗使用“代码 / 调试与输入输出”切换。导入读取期间若继续编辑，应保留当前稿并提示重选，较早文件不能覆盖新稿。重要草稿仍请定期导出。监视暂用十进制常量，需要指针距离时写进源码编译后读取。
6. 按完整手册P01–P10执行真正断网、关闭辅助电脑、关闭重开和全新源码编译调试。桌面检查、保存缓存及添加主屏均不替代G2真机验证。

完整静态包：`app/offline/.local/packages/ipad-offline-debugger-v0.4.3.zip`，19,281,996字节；首次准备小包：同目录`ipad-first-setup-v0.4.3.zip`，18,098字节。均含公开证书及中文步骤，无服务器私钥。完整包用于静态部署或备份，不是IPA，不能在平板解压后通过file://运行。

若入口显示“本版本离线入口需要恢复”，先记录错误，关闭本版本其他窗口，恢复联网后点“联网重新准备资源”，等待全部通过；该操作保留草稿与其他版本。地址打不开、证书警告或准备失败时保留原提示回报1号，不清网站数据、不关闭整个防火墙、不登记为离线通过。
