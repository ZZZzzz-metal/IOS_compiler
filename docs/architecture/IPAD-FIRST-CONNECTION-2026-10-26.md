## 平板依次操作

1. 将 iPad 与当前电脑连到同一 Wi-Fi，保持电脑开机。打开收到的本次 `root-only.mobileconfig`，按系统提示到“设置 → 已下载描述文件”安装；若“已下载描述文件”未出现，可查看“通用 → VPN 与设备管理”。核对名称和配置内容；不一致则停止并回报，不安装陌生管理配置。[Apple：安装描述文件](https://support.apple.com/en-us/102400)
2. 到“设置 → 通用 → 关于本机 → 证书信任设置”，只为 `iPad Debugger Local Test Root a065aa18` 开启完全信任。**这会改变设备的 TLS 信任范围，不限于工作台，需要你手动决定。** 手动安装描述文件不会自动获得 SSL 信任，不通过跳过浏览器警告或关闭证书检查来替代。[Apple：手动信任证书](https://support.apple.com/en-us/102390)
3. 用 Safari 打开下面的固定版本地址。应无证书警告，出现“算法工作台”的“离线准备”页。地址打不开或有警告，先回报原提示，不继续后面的断网步骤。

   [打开本次固定版本](https://100.65.235.35:4187/releases/ipad-web-probe-3551b05827b81bcff5d8823a/index.html)

4. 核对版本 `ipad-web-probe-3551b05827b81bcff5d8823a`，**50项、60,815,496字节，约58.0 MiB**。点“准备离线资源”，保持页面前台，直到显示“已检查50项资源，可以打开工作台”。
5. 留在这个固定版本准备页，通过 Safari 分享菜单“添加到主屏幕”。从主屏图标重新打开，仍联网再点“检查已存资源”；必要时在主屏入口重新准备。通过后打开工作台，点“校验本地资源”。
6. 先告知1号：页面是否打开、50项是否完成、有无错误，并给出iPad型号与iPadOS。之后按通用手册第3节关闭网络和辅助电脑，关闭重开，再做新源码23→28、断点/单步、C42、停止重启43和草稿备份测试。不要把电脑联网时的通过填写为真机离线通过。

## 遇到问题怎样反馈

- 无法导入证书：说清文件存在哪个App、点击后出现什么，不要求你猜系统入口。
- 显示证书警告：记录证书名称、iPad日期时间、警告原文；不要绕过。证书过期、电脑地址变化都需要重新准备入口。
- 一直打不开：确认地址仍是 `100.65.235.35`，电脑服务仍在运行；同Wi-Fi可能存在客户端隔离或系统防火墙限制，由1号排查。不要关闭整个防火墙。
- 资源准备失败：保留错误和已显示的版本/资源数，先不要断网、清除网站数据或删除原草稿。

本次根证书是短期测试用途。结束且不再使用本地入口时，可以在“通用 → VPN 与设备管理”移除仅本次配置，并关闭对应完全信任。保留已导出的草稿备份；添加主屏不能保证网站数据永久保存。
