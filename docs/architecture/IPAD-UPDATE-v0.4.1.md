- 完整Web离线包：`app/offline/.local/packages/ipad-offline-debugger-v0.4.1.zip`，19,273,324字节，约18.38MiB。包含全部资源、许可证、操作手册、版本清单和公开测试证书。
- 首次准备小包：`app/offline/.local/packages/ipad-first-setup-v0.4.1.zip`，16,738字节。包含公开证书、准确入口和操作说明；第一次尚未导入证书时用它。

完整ZIP是Web静态资源备份/部署包。平板通过上面的HTTPS入口准备离线缓存，不能把ZIP在“文件”里解压打开就当成已安装的工作台，也不是原生IPA。

## 已经准备过旧版时

1. 在旧工作台导出“完整草稿”，保存到“我的iPad”；再停止旧调试并关闭工作台。保留原主屏图标和备份，不清除网站数据。
2. 证书继续使用 `iPad Debugger Local Test Root a065aa18`。如果已安装并手动信任，不需要因本次UI更新重复安装；新版本只改变路径，HTTPS域名和端口相同。
3. 首次更新时保持电脑开机、两台设备处于能互访的同一Wi-Fi。用Safari打开新版固定入口，核对 `ipad-web-probe-49831342833678ecf1fccd03`、**50项、60,817,604字节**。
4. 点“准备离线资源”，保持页面前台直到50项全部通过。给**新版准备页**添加主屏图标，例如命名“算法工作台0.4.1”，避免点回旧版。
5. 从新主屏图标仍联网打开，检查资源并打开工作台，再点“校验本地资源”。同一HTTPS源继续使用原IndexedDB草稿；若未出现预期草稿，先核对地址/版本，使用之前导出的完整草稿导入，保留旧数据。
6. 确认新版准备成功后，按 [完整平板操作手册](IPAD-USER-MANUAL.md) 第3节开始断网、关闭辅助电脑和关闭重开测试；以真实观察填写结果。

## 第一次准备时

先把首次准备小包中的公开证书文件通过可信方式传到iPad，按完整手册“如果1号另行提供本地测试证书”一节手动安装并决定是否信任。证书名称同上，根证书SHA-256为 `87991d2b7d332034beddb95ed35ddabc906c0e0b2bd1dd174ec4a25b826e349f`，2026-11-02北京时间09:29:59到期。启用根证书完全信任会改变设备的TLS信任范围，需你手动核对；不通过忽略浏览器警告替代。

之后执行上面的新版准备与主屏步骤。证书警告、地址打不开或准备失败时，把原提示回报给1号，不清草稿、不关闭整个防火墙、不继续登记为离线通过。

## 可以顺便核对的修复

使用5号七行最小源码在第4行设断点并调试到i=0；编辑稿末尾加注释、删除编辑稿断点，再查看旧调试快照。新版应仍显示旧会话第4行“已绑定”，且快照只读；继续后i=1。停止旧会话后重新编译编辑稿，入口暂停后继续应直接退出并返回3，不再命中已删除断点。
