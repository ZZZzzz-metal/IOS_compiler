5. 展开工作台“键盘快捷键”，保持默认“无F键：Control＋数字行”。**Control不是Command（⌘）**，数字用字母上方一行，减号在0右边，无需Fn或Option。

|---|---|---|
| 开始调试 / 暂停后继续 | Ctrl+5 | F5 |
| 编译运行 | Ctrl+6 | Ctrl+F5 |
| 停止 / 取消编译 | Ctrl+Shift+5 | Shift+F5 |
| 光标所在行切换断点 | Ctrl+9 | F9 |
| 单步跳过 | Ctrl+0 | F10 |
| 单步进入 | Ctrl+- | F11 |
| 单步跳出 | Ctrl+Shift+- | Shift+F11 |

断点前先点源码并放好光标；每次调试动作等状态稳定再按下一次。在样例输入、查找、监视、下拉框、弹窗或中文组合输入期间不会触发调试动作；只读调试快照不能改断点。长按不会连发，命令等待确认期间不堆积单步。

可以切换“仅标准F键”，此时关闭数字行替代键。设置按当前浏览器来源保存；页面若提示不能保存，本次仍有效，重开后重新核对。系统可能先截获组合键，没反应时使用同名按钮，并记录按键、焦点及系统表现。不要凭Fn标签认定Fn+数字能产生F键；未实现的重启和运行至光标不映射成其他动作。

完成速查内七动作小操作单后，按总手册P01–P10真正关闭网络和辅助电脑、关闭重开、输入全新源码，验证编译调试和草稿备份。桌面键盘与停服验证不代替iPad验收，G2/G3仍待。
