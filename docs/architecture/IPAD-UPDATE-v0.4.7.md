## 你在平板上的操作

按 [完整操作手册](IPAD-USER-MANUAL.md) 执行。1号会一次只指导当前一步，等你反馈后再继续：

1. 平板和电脑连接同一个可互通Wi-Fi，取得本次证书名称、指纹及固定版本入口。
2. 安装并只信任本次指定的测试根证书，确认Safari打开入口没有安全警告。
3. 完整准备65项资源，从主屏重开后再次检查；打开工作台，确认键盘方案和草稿备份。
4. 开始手册的断网步骤时，关闭平板Wi-Fi/蜂窝并断开辅助电脑，关闭重开新入口。
5. 在断网后输入新代码，按P03–P11逐项测试编译、调试、补全、一次撤销、输入和保存恢复。各项只填实际“通过 / 失败 / 未做”。

你的键盘默认用 **Control＋数字行** 进行调试，不需要Fn或独立F键。代码提示使用按钮或Ctrl+J；Ctrl+Space可能被系统用来切换输入法。完整映射见 [快捷键速查](../../ui/SHORTCUTS.md)。
